# Registros de decisões de arquitetura (ADRs)

Cada decisão importante é registrada num documento curto e imutável. Uma decisão que muda é
substituída por um novo registro, nunca apagada. Os números de 0001 a 0013 estão reservados para as
decisões planejadas para a fundação do projeto, por isso não são necessariamente escritos em ordem
numérica; decisões novas recebem números a partir de 0014.
